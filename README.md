# 📝 880AutoPaper — 考研数学智能组卷

> 基于《880 题》题库的考研数学组卷工具，数一 / 数二，本地运行，永久免费。

## ✨ 功能简介

- **智能组卷**：从 880 题库中按你的需求自动抽取题目，生成一套完整模拟卷（选择题 / 填空题 / 解答题）
- **多维筛选**：按考试类型（数一 / 数二）、篇章（高数 / 线代 / 概率）、难度（基础 / 综合 / 拓展）自由组合
- **去重机制**：组过的题自动记录，下次组卷自动避开，卷子之间不撞题；支持一键重置
- **组卷方案**：保存多套常用配置，随时切换；显示各题型已用 / 剩余数量
- **历史记录**：组卷自动存档，可随时回看
- **公式渲染**：LaTeX 公式正常显示，试卷可在软件内直接阅读

## 🚀 快速上手

1. 选择考试类型（数一 / 数二）
2. 选择篇章（高数 / 线代 / 概率，可多选）
3. 选择难度（基础 / 综合 / 拓展）
4. 点击「+ 新建方案」，配置各题型题数
5. 点击「组卷」，完成！
